## 🚀 How to Use

### Step 1: Install
```bash
git clone https://github.com/ku2507u0309-create/cv.git
cd cv
git checkout cinematic-portfolio
npm install
```

### Step 2: Customize
1. Add profile image to `public/profile.jpg`
2. Edit `src/store/sceneStore.js` with your info
3. Edit `src/components/ContentSection.jsx` with your content

### Step 3: Run
```bash
npm run dev
```

### Step 4: Deploy
```bash
npm run build
# Deploy 'dist' folder to Vercel/Netlify/server
```
